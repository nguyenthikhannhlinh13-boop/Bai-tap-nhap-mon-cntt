## 2. Mô tả bài toán

## 3. Ngôn ngữ lập trình sử dụng
- C++

## 4. Cách chạy chương trình
- Tải file main.cpp về máy tính.
- Mở Terminal tại thư mục chứa file.
- Biên dịch bằng lệnh:

g++ main.cpp -o main

- Chạy chương trình:

./main

Tong hai so la: 12
